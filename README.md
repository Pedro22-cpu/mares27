# Real Estate Landing Page – Template

Cópia limpa do projeto "Real Estate Landing Page", para criar novas landing pages.

## Como usar
1. Duplicar esta pasta e dar o nome do novo imóvel.
2. `pnpm install` (ou `npm i`)
3. `pnpm dev`

## O que alterar numa nova landing page
- `src/site.config.ts` – **ficheiro principal**: morada, preços, links dos anúncios, specs, fotos da galeria, dados e redes sociais do consultor, rodapé
- `src/app/App.tsx` – estrutura e textos longos das secções (só se precisares de mudar o layout)
- `src/locales/pt|en/translation.json` – textos PT/EN
- `src/assets/` – fotos, plantas, vídeo, logos, QR, perfil do consultor
- `public/` – favicon e imagem de cover (partilha)
- `index.html` – título e meta tags
